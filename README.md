# DeclaBuddy

DeclaBuddy is an open-source web application designed to simplify filling in and generate PDF expense claim forms.

## Features
- Automatic Dutch address lookup by postcode + house number (powered by SQLite & local dataset).
- Built-in digital signature pad (draw or upload).
- Automatic PDF compilation & receipt attachment merging (fitted to A4).
- Dual language support (Dutch & English).
